#### Project Title: House Price Prediction. 

##### Purpose: 
. To Use Machine Learning through Python to predict the price of housing in India, base on the analyze data gathering before.

##### Dataset:
https://www.kaggle.com/datasets/sukhmandeepsinghbrar/house-prices-india

This dataset contains residential property data from India, including features such as bedrooms, bathrooms, living and lot area, floors, condition, grade, location, nearby schools, airport distance, and property price. It is suitable for real estate analysis and housing price prediction across different regions in India.

There are 23 columns in this dataset.
